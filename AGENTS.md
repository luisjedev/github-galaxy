# AGENTS.md

## Proyecto

GitGalaxy es una aplicación web 3D que convierte perfiles públicos de GitHub en sistemas solares explorables. Usa React, TypeScript, React Three Fiber/Three.js y Vite. No tiene backend: consulta la API pública de GitHub desde el navegador.

## Comandos

- `pnpm install`: instalar dependencias.
- `pnpm dev`: iniciar el entorno local.
- `pnpm typecheck`: comprobar tipos.
- `pnpm lint`: ejecutar ESLint.
- `pnpm test`: ejecutar tests unitarios con Vitest.
- `pnpm test:e2e`: ejecutar pruebas E2E con Playwright.
- `pnpm test:all`: ejecutar todas las pruebas.
- `pnpm build`: generar el build de producción.

## Indicaciones

- Mantén los cambios simples, tipados y coherentes con la estructura existente.
- Ejecuta las verificaciones relevantes después de modificar código.
- Para pruebas manuales en el navegador, puedes usar el MCP de Playwright para iniciar la aplicación y comprobar su estado y comportamiento.
